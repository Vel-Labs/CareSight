# CareSight Thesis

CareSight Hub is strongest when it is framed as a local care event engine, not a fall detector or camera viewer.

The meaningful product loop is:

```text
observe locally
  -> classify cautiously
  -> store structured memory
  -> notify an authorized caregiver
  -> wait for human acknowledgement
```

The hackathon advantage is the combination of YOLO26 MLX on-device vision, bounded event contracts, local SQLite memory, and clear safety posture.
