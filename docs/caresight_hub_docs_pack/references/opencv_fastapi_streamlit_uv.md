# OpenCV, FastAPI, Streamlit, and uv Reference

## Role in CareSight

These are practical support tools.

## OpenCV

Use for webcam/video capture and frame handling if YOLO26 runner does not already provide all capture functionality needed.

## FastAPI

Good for a local API/dashboard backend, event endpoints, and alert actions.

## Streamlit

Good for rapid dashboard development with minimal frontend work.

## uv

Good for Python environment and package management.

## MVP recommendation

Choose either FastAPI or Streamlit. Do not build both unless necessary.

- Streamlit is fastest for demo UI.
- FastAPI is better for structured API/action flows.
