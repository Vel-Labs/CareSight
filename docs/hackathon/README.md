# Hackathon Notes

Use this folder for challenge rules, submission checklist, judging criteria, demo scripts, and the bounded hackathon roadmap.

## Project

CareSight Hub

## Core Submission Thesis

CareSight Hub is a local-first care event engine that uses YOLO26 MLX on Apple Silicon to observe possible safety and routine events, store structured records locally, and alert permissioned caregivers.

CareSight shows a bounded local loop: camera input, YOLO26 MLX perception, structured care event, local journal, and caregiver alert.
