# v1 Hackathon MVP

## Goal

Ship the bounded care event demo:

- one camera source
- YOLO26 MLX local perception
- `possible_floor_stay`
- `medication_routine_likely_observed`
- SQLite event memory
- daily journal
- caregiver alert
- local dashboard

## Constraint

The system must use cautious event language and require human confirmation for safety-critical conclusions.
