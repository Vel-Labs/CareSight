# Camera Protocols and Home Integration Reference

## Role in CareSight

Camera adapters determine how the base unit gets frames.

## Recommended priority

1. Webcam / USB camera.
2. iPhone Continuity Camera.
3. RTSP IP camera.
4. ONVIF local cameras.
5. Home Assistant camera entities.
6. Ring/Nest optional adapters.

## ONVIF

Use for local IP camera interoperability in future home/facility pilots.

## Home Assistant

Use as a bridge to camera entities and smart-home setups.
